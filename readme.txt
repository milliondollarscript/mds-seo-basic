Add search metadata, social cards, structured data, canonical controls, and scalable sitemaps to Million Dollar Script sites.

== Description ==

SEO Basic adds practical search metadata and discovery controls for Million Dollar Script pages, posts, grids, and archives. It supports page-level titles and descriptions, canonical URLs, robots controls, social sharing images, structured data, and paginated sitemap sections.

When a recognized full SEO suite is active, overlapping public output is paused to avoid duplicate metadata. SEO Basic does not promise search rankings or replace content, performance, accessibility, or marketing work.

== Installation ==

1. Install and activate Million Dollar Script.
2. Install and activate this extension.
3. Open Million Dollar Script > Extensions > SEO Basic.
4. Review metadata, social, schema, sitemap, and conflict settings.
5. Check representative public pages and sitemap sections before submitting them to search engines.
